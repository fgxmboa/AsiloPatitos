# AsiloPatitos

## Descripción funcional
AsiloPatitos es un sistema web para la gestión del Asilo de Ancianos “Patitos del Retiro”. Su propósito es mejorar la administración de los procesos internos mediante la automatización y centralización de la información relacionada con pacientes, habitaciones, empleados, reservaciones, tratamientos, medicamentos, pagos y reportería.

## Objetivo del sistema
Automatizar y centralizar la gestión institucional del asilo para permitir un acceso más rápido, seguro y confiable a los datos, optimizar el tiempo del personal y mejorar la atención a los residentes.

## Problema que resuelve
El sistema busca resolver los problemas derivados del manejo manual de la información, tales como demoras, errores humanos, duplicidad de datos y dificultades en el control administrativo y operativo del asilo.

## Arquitectura general
El sistema fue diseñado bajo una arquitectura en capas basada en el modelo MVC (Modelo–Vista–Controlador), separando la lógica de negocio, la interfaz de usuario y el control de flujo de la aplicación para facilitar el mantenimiento y la escalabilidad.
